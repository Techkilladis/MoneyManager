# Triage Labels

Canonical GitHub labels used for issue triage and lifecycle management in `Techkilladis/MoneyManager`:

- `needs-triage`: Newly opened issue awaiting categorization and scoping.
- `needs-info`: Blocked waiting on clarification or data from reporter/human.
- `ready-for-agent`: Issue is fully specified, verified, and ready for autonomous agent execution.
- `ready-for-human`: Issue requires human decision-making, physical device access, or external credential setup.
- `wontfix`: Work that will not be pursued.
